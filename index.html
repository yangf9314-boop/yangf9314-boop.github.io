作品一：生活大爆炸台词检索系统

面向抖音创作者的小工具：输入中英文关键词，快速从《生活大爆炸》台词里找到适合做视频切片的那句，并直接预览对应片段、复制分享链接。当前只收录第一季第一集，作为可跑通的 demo。前端用 Vite + React + TypeScript，台词数据放在 Supabase，视频片段存在 Cloudflare R2，素材用 Python 和 ffmpeg 预处理，页面部署在 Netlify。整条链路围绕搜索、播放和分享展开。
